# Browser prototype

Open the repository root `index.html` in a modern browser. The UI is mobile-responsive.

Features: sample Short preview, editable sample title/script, locally persisted approval state, approve/request changes/reject controls, approval invalidation on edits, and a queue/settings view.

**This is a static interactive demo, not the production app.** It does not produce real videos, call AI, synchronize across devices, schedule tasks, access YouTube, or earn money. Local storage can be cleared by the browser. The sample is not fact-checked or rights-cleared for publication.

GitHub Pages workflow is provided; it may require repository Settings > Pages > Build and deployment > Source: GitHub Actions, and GitHub permissions to deploy. A public GitHub repository exposes its source and deployed demo to anyone.

Production needs server-side authenticated approval, persisted evidence, a video generator, provider integrations, and secure OAuth before any real publishing.
